# PlanMeet — веб-сервис для согласования времени мероприятий

Веб-приложение на Django для группового подбора удобного времени встречи.
Организатор создаёт событие с вариантами дат и времени, отправляет ссылку
участникам, а сервис автоматически определяет лучший вариант по итогам голосования.

Проект разработан в рамках выпускной квалификационной работы (2026).

## Возможности

- Регистрация и авторизация организаторов
- Создание события с произвольным числом вариантов дат/времени
- Голосование участников по уникальной ссылке **без обязательной регистрации** (Да / Возможно / Нет)
- Защита от повторного голосования (на уровне сессии и уникального ограничения в БД)
- Автоматический подсчёт результатов и определение лучшего варианта
- Наглядное отображение результатов с выделением победителя
- Закрытие голосования вручную или по дедлайну
- История событий в личном кабинете организатора

## Технологии

- **Backend:** Python 3.10+ / Django 4.2
- **База данных:** SQLite (по умолчанию) с возможностью переключения на MySQL
- **Frontend:** HTML5 / CSS3 / Vanilla JavaScript

## Архитектура

Проект построен по паттерну MTV (Model–Template–View) и разделён на приложения:

- `core` — главная страница
- `users` — регистрация и аутентификация
- `events` — основная логика: модели `Event`, `TimeSlot`, `Vote`, создание событий,
  голосование, подсчёт и отображение результатов

## Модели данных

- **Event** — событие: название, описание, организатор, дедлайн, статус
- **TimeSlot** — вариант даты/времени для голосования (привязан к `Event`)
- **Vote** — голос участника за конкретный слот (Да / Возможно / Нет)

## Логика подсчёта

Каждый голос имеет вес: «Да» = 1 балл, «Возможно» = 0.5 балла, «Нет» = 0 баллов.
Лучшим объявляется вариант с наибольшей суммой баллов.

## Запуск локально

```bash
# 1. Клонировать репозиторий
git clone https://github.com/<ваш-логин>/planmeet.git
cd planmeet

# 2. Создать и активировать виртуальное окружение
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. (Опционально) задать переменные окружения
# Скопировать .env.example в .env и при необходимости заполнить.
# Без этого проект запустится на SQLite, письма выводятся в консоль.

# 5. Применить миграции
python manage.py migrate

# 6. (Опционально) создать администратора
python manage.py createsuperuser

# 7. Запустить сервер разработки
python manage.py runserver
```

Открыть в браузере: http://127.0.0.1:8000/

## Конфигурация через окружение

Секреты и параметры окружения (SECRET_KEY, доступ к БД, SMTP) читаются из
переменных окружения. Полный список — в файле [`.env.example`](.env.example).
Реальный файл `.env` в репозиторий не добавляется.
